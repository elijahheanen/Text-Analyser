# Text Analyser

## Why:

I built this primarily because I wanted to optimise my French revision (particularly listening) by finding the most common words in the transcripts.

## Use:

Put the file you wish to count the words of into the files/ dir and change the code near the top on the `with open("files/file.txt") as file: ` and replace `file.txt` with your filename. Run the program with `python main.py` and it should output a dictionary of each word and its frequency to standard out (probably terminal).
